# ВАСИОНА — Дневник развоја

**03.05.2020.** — Написана оригинална концептуална белешка (изворни PDF):
идеја о суверенитету Србије над ваздушним и свемирским простором изван
атмосфере, праћење сателита и наплата накнада.

**17.09.2026, сесија 1** — Прегледан концепт. Одмах истакнуто кључно правно
питање: члан II Уговора о космосу забрањује национално присвајање свемира
изнад ~100 km, тако да накнаде за прелет сателита тренутно немају правни
основ (за разлику од ваздухопловних накнада за прелет, које почивају на
признатом сувереном ваздушном простору). Израђено: назив бренда (ВАСИОНА),
логотип (SVG), кандидати за домен, територијални оквир (Слој 1 — суверени
ваздушни простор / Слој 2 — зона надзора), скица софтверске архитектуре и SQL
шеме, модел монетизације у два тока (стваран SaaS наспрам хипотетичке табеле
накнада), фазни план развоја. Испоручено као Markdown пакет + датотека
логотипа.

**17.09.2026, сесија 2** — Израђена радна интерактивна демонстрација
(`vasiona_tracker.html`, објављена као артефакт): стварна SGP4 пропагација
МСС-а (ISS) на основу јавног NORAD скупа орбиталних елемената (епоха
13.05.2026), покренута уживо у прегледачу, уз симулирану вишесателитску
констелацију ради визуелне густине. Геозаштита Србије имплементирана као
поједностављен правоугаони оквир географских ширина/дужина. Забележено
ограничење: објављене артефакт странице не могу уживо преузимати спољне
изворе орбиталних елемената (CSP ограничава дозвољене host-ове за
скрипте/стилове), стога демонстрација користи уграђени снимак података.

**17.09.2026, сесија 3** — Израђен други интерактивни артефакт,
`vasiona_revenue_simulator.html`: подесив хипотетички калкулатор који
процењује приход од „сателитских накнада" по држави уколико би правило о
забрани присвајања из Уговора о космосу било напуштено. Преузет стваран,
актуелан број активних сателита (~16.500, септембар 2026) као подразумевана
вредност. Изричито означено као сценарио алат у целом тексту, не као
прогноза. Истакнут кључан налаз: модел рангира државе по распону географске
дужине исток-запад, тако да државе великих копнених површина (Русија,
Канада, САД, Кина) доминирају без обзира на економску величину — супротно
претпоставци из оригиналне концептуалне белешке да би „свемирске
суперсиле" биле у неповољном положају због своје величине.

**17.09.2026, сесија 4** — Израђена стварна, покретљива Next.js/Vercel
платформа:
- `app/api/cron/fetch-tles` — Vercel Cron крајња тачка, преузима **уживо**
  каталог орбиталних елемената са CelesTrak-а (јаван, бесплатан, без API
  кључа), покреће стварну SGP4 пропагацију на серверу (преко `satellite.js`,
  компатибилно са Node.js, иста библиотека као у демонстрацији у прегледачу),

- `app/api/ledger` — комбинује (а) стварно забележене догађаје из cron
  задатка са (б) моделованом статистичком проценом која покрива период
  2020. → прво покретање платформе, пошто дословна историјска реконструкција
  орбита уназад до 2020. није изводљива без специјализованог историјског
  архива орбиталних елемената.
- `docs/BUSINESS_PLAN.md` (и `.sr.md`) — изричито раздваја стваран производ

  хипотетичког сценарио модела (Ток Б: процена накнада 2020–данас), уз
  напомену о Уговору приложену уз сваку појаву бројки из Тока Б.

## Познате поједностављене претпоставке, присутне у свакој верзији
1. **Геозаштита Србије** је правоугаони оквир географских ширина/дужина, не
   стваран полигон државне границе — прецењује број прелета који само окрзну
   углове оквира.
2. **Историјска табела накнада (2020→данас)** је статистичка процена на
   основу годишњих бројки популације сателита, не дословна историјска
   орбитална реконструкција по сваком сателиту.
3. **Фактор покривености (75%)** и **орбите/дан (15)** су заокружене
   илустративне претпоставке, не измерене константе — обе су изложене као
   подесиви параметри (environment променљиве у платформи, клизачи у
   самосталном симулатору) уместо да буду тврдо кодиране.
4. **Накнада по прелету (подразумевано 25 $)** је илустративна, лабаво
   ослоњена на део типичног распона цивилних ваздухопловних накнада за
   прелет.
