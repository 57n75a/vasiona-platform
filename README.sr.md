# ВАСИОНА — Орбитирање сателита

*(For English, see [README.md](./README.md))*

Покретљива Next.js/Vercel платформа која:
1. Извршава заказан cron задатак који преузима **уживо** скупове орбиталних
   елемената сателита (TLE) са CelesTrak-а,
2. Прорачунава стварну позицију сваког сателита помоћу SGP4 (`satellite.js`),
3. Бележи сваки сателит чија путања по тлу пређе преко Србије у Postgres базу,
4. Приказује контролну таблу са тим стварно забележеним прелетима, уз
   **хипотетичку** табелу накнада — колико би ти прелети „вредели" када би
   накнаде за прелет сателита постојале (тренутно не постоје — видети испод).

Платформа и документација доступне су **двојезично** — контролна табла има
преклопник језика (горе десно), а сваки документ у `docs/` постоји у
енглеској (`.md`) и српској (`.sr.md`) верзији.

## ⚠️ Прочитати пре било каквог јавног покретања
Бројке у доларима које ова платформа израчунава представљају **сценарио
модел**, не стваран производ или фактуру. Уговор о космосу из 1967. (члан II)
забрањује национално присвајање свемира, тако да тренутно не постоји правни
основ за наплату накнаде сателиту за прелет — за разлику од накнада за
прелет ваздухоплова, које почивају на признатом сувереном ваздушном
простору. Пун контекст у `docs/BUSINESS_PLAN.sr.md`. Не представљати
хипотетичке бројке претплатницима или инвеститорима без те напомене.

## Шта је стварно, а шта симулирано
| Део | Статус |
|---|---|
| TLE подаци (cron задатак) | 🟢 Стварно — уживо преузимање са CelesTrak-а |
| SGP4 пропагација | 🟢 Стварно — иста библиотека као у ранијој демонстрацији у прегледачу, покренута на серверу |
| Геозаштита Србије | 🟢 Стваран полигон границе — провера тачка-у-полигону са ~130 тачака |
| Оператор/држава по сателиту | 🟡 Хеуристика — препознавање обрасца из назива каталога (нпр. „STARLINK-1007" → SpaceX/САД), није званични регистарски податак |
| Карта уживо | 🟢 Стварно — SVG рендерован на серверу из стварног полигона границе, са стварно забележеним прелетима приказаним на њему |
| Бројке „стварно забележено" у табели накнада | 🟢 Стварно — стварни прелети које је ова инстанца забележила од покретања |
| Бројке „моделовано 2020→данас" у табели накнада | 🟡 Статистичка процена — видети `lib/historicalModel.ts` |
| Накнада по прелету, фактор покривености | 🟡 Илустративно, подесиво преко environment променљивих |
